# 🏷️ Don Descu LSM (Próximamente)

¡El comparador de precios colaborativo de Libertador San Martín!

**Don Descu LSM** nace para empoderar a los vecinos de Libertador San Martín. A través del crowdsourcing, los propios usuarios notifican precios bajos, permitiendo que toda la comunidad encuentre la opción más barata en tiempo real.

> **Nota:** La rama `main` contiene actualmente el despliegue de la página de espera. Todo el desarrollo activo se está llevando a cabo en la rama `develop`.

## 🛠️ Stack (En desarrollo)
Estamos construyendo una plataforma robusta utilizando:
* **Frontend:** Next.js (App Router)
* **Backend:** NestJS & PostgreSQL
* **Auth:** Better Auth
* **ORM:** Prisma

---
Para ver el progreso del proyecto cambia a la rama [develop](https://github.com/HarrysonLadines/dondescu-lsm/tree/develop).
